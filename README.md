# Angular Todo App с автоматизацией на Playwright

Данный репозиторий содержит демонстрационное Angular-приложение (список задач), интегрированное с публичным REST API ([JSONPlaceholder](https://typicode.com)), а также комплект сквозных (E2E) автотестов, разработанных на [Playwright](https://playwright.dev).

В ходе исследовательского тестирования приложения был обнаружен и задокументирован критический архитектурный баг интеграции (ошибка `500 Internal Server Error` при попытке отредактировать вновь созданные задачи с ID 201), который успешно воспроизводится и локализуется написанными автотестами.

---

## 🛠 Инструкция по развертыванию и запуску проекта

Для запуска проекта локально на вашей машине (или виртуальной среде Linux) выполните следующие шаги:

### 1. Клонирование репозитория и установка зависимостей
Склонируйте проект и перейдите в его корневую директорию:
```bash
git clone https://github.com/valdik305/angular-todo-playwright-qa.git
cd angular-todo-playwright-qa
```

Установите все необходимые npm-пакеты для работы Angular и Playwright:
```bash
npm install
```
*(Если в Linux возникнет ошибка прав доступа EACCES, выполните `sudo chown -R $USER:$USER .` и повторите установку).*

### 2. Запуск локального сервера приложения
Запустите Angular-приложение в режиме разработки:
```bash
npm start
```
После этого приложение станет доступно в браузере по адресу: **`http://localhost:4200`**

## 🚀 Инструкция по запуску и прогону автотестов

Все тесты находятся в папке `tests/` и настроены для кроссбраузерной проверки. перед первым запуском тестов убедитесь, что локальный сервер Angular (`http://localhost:4200`) запущен и работает.

### 1. Подготовка окружения Playwright
При первом запуске необходимо скачать служебные бинарные файлы браузеров и системные зависимости:
```bash
npx playwright install
sudo npx playwright install-deps
```

### 2. Запуск тестов в фоновом режиме (Headless)
Запустите все тест-кейсы во всех настроенных браузерных движках (Chromium, Firefox) одной командой:
```bash
npx playwright test
```

### 3. Запуск тестов с отображением браузера (Headed)
Если вы хотите визуально наблюдать за действиями робота на экране в реальном времени:
```bash
npx playwright test --headed
```

### 4. Просмотр детального HTML-отчета
После завершения прогона Playwright генерирует интерактивный отчет. Чтобы открыть его, выполните:
```bash
npx playwright show-report
```
Сервер отчетов запустится локально и предоставит ссылку (например, `http://localhost:9323`), где можно детально изучить шаги выполнения, логи и скриншоты упавших тестов.
